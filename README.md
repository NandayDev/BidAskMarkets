# BidAskMarkets

Progetto per il calcolo degli spread per gli ETF, sugli exchange EIX (di Scalable), LS (appoggio attualmente di Trade Republic) e XETRA.

Il progetto C# serve per scaricare i dati dai tre exchange (EIX, LS, XETRA). Utilizza .NET 10, ed è stato eseguito su OS Linux.

La cartella "data" contiene i dati già pronti per poter eseguire il codice Colab su https://colab.research.google.com/drive/1qWMHexKhT4Bnv__yzQH2ff9r4qNJ7iDH?usp=sharing
